# Android 手机与手环：逐步设置

先在电脑解压 Windows 便携包，双击 **01-首次配置.cmd**。电脑打开的记事本有“服务器地址”和“主题名称 / Topic”，下面会用到。没有记事本时打开解压目录的 `app/phone-subscription.txt`。

## 一、下载并安装手机 App

在 **Android 手机**打开 [ntfy 官方 APK 下载链接](https://github.com/binwiederhier/ntfy-android/releases/download/v1.25.2/ntfy-1.25.2-fdroid-release.apk)，下载的是 `ntfy-1.25.2-fdroid-release.apk`。

1. 浏览器下载完成后，点这个 APK 文件。下载列表找不到时，到手机“文件管理 → 下载”查找。
2. 提示不允许浏览器安装应用时，按系统提示进入设置，允许本次从该来源安装，再返回安装页面。
3. 安装完成后点“打开”，应用名称为 **ntfy**。
4. 遇到“是否允许发送通知”时，选择允许。

也可用 [ntfy 官方页面](https://docs.ntfy.sh/subscribe/phone/)列出的 Google Play 或 F-Droid 安装方式。GitHub [手机发布页](https://github.com/binwiederhier/ntfy-android/releases/latest)的 **Assets / 资源** 中，选择名称含 `fdroid-release.apk` 的文件。`.aab` 无法作为普通 APK 直接安装，`debug.apk` 是调试构建。

**电脑的 ZIP 装在电脑，手机的 APK 装在手机。** 手环继续通过原来的配套 App 接收手机通知。本指南面向 Android，iPhone 不在当前便携方案的验证范围。

## 二、订阅电脑生成的主题

电脑记事本中类似这样：

```text
服务器地址：https://ntfy.sh
主题名称 / Topic：agent-一长串随机字符
```

示意文字不用照抄，请填自己电脑实际生成的名称。

1. 在手机 **ntfy** 首页点 **`+` / 添加订阅**。
2. 找到 **主题名称 / Topic name**，填入记事本中完整的 `agent-...`。
3. 检查服务器，默认应为 **`https://ntfy.sh`**；需手动选择时填这一项。自建服务器则填电脑实际显示的地址。
4. 点 **订阅 / Subscribe**。回到列表应能看到新主题，点进去可查看此主题的消息。

主题一栏只填 `agent-...`，不填完整 URL、不加引号、不多复制空格。两边的服务器和主题要完全一致。重新运行 01 会保留现有主题，无需每次重新订阅。

电脑和手机不在一起时，可用自己信任的方式转发这两项信息；不要把主题发到公开群聊、截图或在线二维码生成服务。受保护的自建服务器还需在手机配置对应订阅权限。

## 三、允许手机后台接收

到手机 **设置 → 应用 → ntfy** 检查以下项目。不同品牌可能叫“应用管理”“耗电管理”或“后台活动”。

- **通知：允许。** 同时检查通知渠道是否被静音。
- **电池：允许后台活动 / 不限制。** 避免锁屏后被冻结。
- **联网：允许后台使用网络。** 使用移动网络时也需允许。
- **自启动：允许。** 手机系统提供此项时按需开启。

先让手机 ntfy 打开着测试，再测试锁屏后的接收。只有打开 App 才能收到时，优先检查后台联网和电池限制。声音、振动仍受系统勿扰和通知渠道影响。[ntfy 手机端官方说明](https://docs.ntfy.sh/subscribe/phone/)

## 四、让手环接收 ntfy 通知

这里打开 **手环原来的配套 App**，例如“小米运动健康”。

1. 在配套 App 中确认手环已连接，手机蓝牙开启。
2. 打开手环对应的 **设备页面 → 应用通知 / 消息提醒**。
3. 开启应用通知，在应用列表或“其他应用”里找到 **ntfy**，允许转发。
4. 系统提示给配套 App 开启 **通知使用权 / 通知读取权限** 时，按提示授予。
5. 检查手环勿扰、睡眠模式、“仅佩戴时提醒”“仅手机锁屏时提醒”等条件。

菜单随品牌、型号和版本变化。其他第三方应用也无法转发时，先按设备官方说明恢复配套 App 与手环的消息提醒功能。

## 五、用同一条测试消息检查三段链路

回到电脑，双击 **02-发送测试通知.cmd**，依次检查：

| 检查位置 | 正常结果 | 失败时优先检查 |
| --- | --- | --- |
| 电脑窗口 | “服务器已接受测试通知” | 电脑网络、服务器地址、访问权限 |
| 手机 | ntfy 弹出通知，主题消息列表也能看到 | 服务器和主题；通知权限与后台联网 |
| 手环 | 显示消息或振动 | 配套 App 的 ntfy 转发、通知读取权限、蓝牙与勿扰 |

电脑成功只表示服务器接受请求。手机正常、手环不提醒时，先检查配套 App，不必反复删主题或重新配置电脑。

三段都正常后，双击电脑 **03-开始监听.cmd**。看到成功后，在支持的软件里发起一个新任务，持续超过默认的 3 秒门槛，完成后检查自动提醒。历史任务不会全部补发。

## 六、只在自动提醒时出问题

1. 双击 **04-查看状态.cmd**，确认监听正在运行。
2. 确认是在监听启动后发起并完成的新任务。
3. 自定义数据目录按 [高级配置](configuration.md) 指定路径。
4. 检查旧文件夹、源码前台窗口、计划任务是否同时运行另一份监听。
5. 软件升级可能改变数据格式。反馈时说明软件版本、哪种事件没有提醒，并提供已隐藏私人内容的错误信息。

便携包日志位于 `app/logs/`。不要公开主题、令牌、完整聊天正文或会话数据库。
