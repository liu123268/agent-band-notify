# Windows 后台运行与开机启动

## 日常使用

双击便携包的 **03-开始监听.cmd**，看到“后台监听已启动”后即可关闭窗口。**04-查看状态.cmd** 查看是否运行，**05-停止监听.cmd** 停止本目录监听。默认不创建计划任务、服务或开机启动项。

编号入口使用附带的 `app/runtime/node.exe`，不需要系统安装 Node，也不依赖 VBScript。源码目录使用编号入口时需先安装 Node.js。

## 登录 Windows 后自动启动（可选）

先按 README 完成配置、订阅和测试，再进行此项。

1. 在解压目录中，右键 **03-开始监听.cmd** →“创建快捷方式”。Windows 11 可能需先点“显示更多选项”。
2. 按 **Win + R** 打开“运行”，输入 **`shell:startup`**，按回车，打开当前用户的启动文件夹。
3. 把刚创建的快捷方式放进启动文件夹。原程序仍保留在原目录。
4. 下次登录 Windows 时会启动。确认窗口显示成功后可按任意键关闭，后台监听继续运行。

05 只停止当前进程；保留快捷方式时，下次登录仍会启动。**取消自动启动**：再次用 `shell:startup` 打开启动文件夹，删除这个快捷方式，再用 05 停止当前监听。

移动文件夹前先 05 停止；移动后重新创建指向新位置的快捷方式。一次保留一套启动方式。

## 以前已经用过 VBS 或计划任务

旧版源码中的 `一键启动.vbs`、`看监听状态.vbs`、`装进任务计划程序.vbs` 保留用于已有部署，Windows 便携包使用上面的编号入口。

以前注册的 **`band-notify-watchers`** 任务可能在监听停止后重新拉起进程。按 **Win + R** 输入 **`taskschd.msc`**，在“任务计划程序库”查看该任务的“操作”，核对确实指向自己要停的旧目录，再禁用对应任务。启动文件夹若有旧版 `band-notify-watchdog.vbs`，也要核对它指向的项目位置。

自动重启入口与手动停止是两层：禁用任务或删除快捷方式防止以后启动，05 停止当前这份程序。不要批量终止所有 Node 进程，以免影响其他软件。

VBS 依赖 Windows Script Host / VBScript，系统策略可能限制它。编号 CMD 入口无需 VBS。高级用户手动创建计划任务时，应明确填写本程序的绝对路径，并核对任务不会重复运行。

## 源码前台运行

在源码目录执行 `node tools/agent-watch.js`，会在当前窗口持续监听；保留窗口，按 **Ctrl+C** 停止。切换到编号后台入口前，先停止此前台进程，以免同一事件提醒两遍。
